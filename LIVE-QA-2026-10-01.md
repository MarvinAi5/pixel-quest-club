## Defects found and source changes

1. **Avatar artwork bleeds from neighboring rows.** Several avatar buttons showed a thin sliver of an adjacent character above/below the intended portrait. The 200-pixel source crop exceeded the roughly 177–185-pixel row spacing. Reduced the shared portrait crop to 170 pixels for both CSS avatars and canvas companions. Existing browser QA now captures an avatar-grid screenshot for visual review.
2. **Later remains enabled for the last command.** The last command cannot move later, but its button remained enabled and did nothing. It now disables at the end of the program, matching Earlier at the beginning. Existing browser QA checks the last command's disabled control.

These changes need deployment before they affect the public site. No server, database, account, lesson content or operational configuration was changed by this investigation.

- **Public load/security/backup tests:** no live load flood, vulnerability scan, backup restore or infrastructure mutation was performed. Previously passed isolated 100-session tests are not a public VPS stress test.
